# III.VehicleDeformation

Work-in-progress GTA III vehicle mesh deformation plugin.

Target: GTA III 1.0 EN. Binary behavior is grounded against the GTA III executable/IDB; Plugin-SDK is pinned to revision `62fd0ef66f704cf7e649607b57cc6e8097ed6e58`.

This repository is an active reverse-engineering/deformation-behavior workbench. The current checkpoint is not considered finished or visually correct yet.
