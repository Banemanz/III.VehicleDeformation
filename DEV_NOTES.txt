GTA III / Vice City stock-code comparison
- GTA III CAutomobile::VehicleDamage = 0x52F390.
- Vice City CAutomobile::VehicleDamage = 0x59B550.
- The routines are clearly the same lineage. Both contain a 25.0 damage gate and the
  same >50 player-impact shake expression using 0.4, 2000.0, +100.0 and a 250.0 cap.
- Member offsets differ (for example the mass field), so VC offsets/layouts are not used.
- GTA III SetBumperDamage/SetPanelDamage/SetDoorDamage use the same stock visibility
  family as VC: component frame atomics are switched and detached by damage status.
- GTA III keeps a helper SetComponentVisibility at 0x5300E0; VC inlines the equivalent
  RwFrameForAllObjects/SetVehicleAtomicVisibilityCB work in these damage routines.

What changed from the previous III-native refactor
1. Removed the axial/ellipsoidal CrushField. It could reject visible body vertices when
   the collision-model contact sat slightly behind the render shell.
2. Replaced it with a spherical DentField around the exact retained collision point.
3. Impact distance is measured from each immutable original/rest vertex, transformed
   through that atomic's CURRENT frame for this impact.
4. Existing deformation is NOT included in the next impact distance test. This restores
   the late archived III rule that prevents a dent from chasing itself into spikes/sails.
5. Baseline displacement is simply authoritative inward collision push * falloff * depth.
   No rim pull, ripple, random noise, crinkle, broad panel smoothing or cage solver.
6. GTA III raw damage impulse remains the strength domain. The VC ASI's mass-scaled
   impact multiplier is deliberately not imported even though the stock III/VC damage
   routines are closely related.
7. Radius grows with severity, retaining the useful simple VC idea while using III's
   own impulse range.
8. WheelSync remains implemented but defaults OFF so body deformation can be stabilized
   independently from GTA III's render-time wheel-matrix rewrite.

Kept from the cleaner III-native shell
- Exact GTA III ApplyCollision/ApplyCollisionAlt call-site capture.
- Highest returned collision impulse wins the render contact for the frame, mirroring
  GTA III's damage-record selection.
- VehicleDamage zero-argument fallback to m_fDamageImpulse/m_nDamagePieceType.
- Per-vehicle private owned geometry; no VehicleExtender.
- Both currently hidden and visible non-wheel atomics receive private geometry so stock
  OK/DAM visibility switching does not fall back to shared undeformed model geometry.
- RpGeometryLock/Unlock only; no manual repEntry destruction.
- Explicit set-model/destructor state cleanup.
- CAutomobile::Fix restores rest geometry.
